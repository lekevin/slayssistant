# Slay the Spire: The Board Game — Card, Curse, Relic & Potion Compendium

Transcribed from "Slay The Spire: The Board Game Compendium" (source: https://rustywolf.github.io/sts/#/), a fan-made
visual reference. This is NOT the official rulebook — treat it as a card-text reference. If a ruling seems to
conflict with the official rulebook excerpts elsewhere in this corpus, the rulebook wins; use this file mainly to
answer "what does card X do" / "how much damage does X do" questions.

## Icon legend (best-effort, inferred from context — not officially confirmed)
- [dmg N] = deal N damage (red slash/sword icon)
- [AOE dmg N] = deal N damage to an entire row (flame icon prefix before a damage number; hits every enemy in the
  targeted row, this game's equivalent of "hits all enemies")
- [blk N] = gain N Block (blue droplet/shield icon)
- [nrg N] = gain N Energy (orange circle icon)
- [gold N] = gain N Gold (gold coin icon)
- [Vulnerable] = apply Vulnerable (broken-heart icon; a number is shown next to it when the amount is specified,
  otherwise the amount wasn't legible on the card face)
- [Weak] = apply Weak (grey spiral/tornado icon)
- [Poison] = apply Poison (skull icon)
- [Innate?] = small padlock icon in a card's bottom-right corner — likely denotes an "Innate"-style keyword
  (starts in your opening hand), unconfirmed
- [die: X] = this game uses a shared action die; effect triggers based on the rolled face (see rulebook for the
  exact die-face table)
- Watcher-specific icon of praying hands = Mantra (this class's stance-charging resource)
- Stances (Wrath / Calm / Neutral) and Orbs (Lightning / Frost / Dark) are written out in full where the card text
  spells them out

Format per entry: **Card Name** (Cost) [Type] — effect text.
